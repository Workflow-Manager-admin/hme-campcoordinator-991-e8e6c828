# Supabase Table Requirements for "events" (Camp Shared Calendar)

For the "Event Calendar" module to function, Supabase must provide a table named `events` with at least these columns:

- `id`: primary key, bigint or uuid, auto-increment or generated
- `title`: text/varchar, event title (required)
- `description`: text/varchar, full description
- `start`: timestamp (ISO string), event start datetime (required)
- `end`: timestamp (optional, for events with end time)
- `category`: text/varchar, event type/category (e.g., "Meal", "Workshop", etc)
- `created_by`: text/varchar (email or user id)
- `created_at`: timestamp, insertion timestamp
- `announcement`: boolean, whether this is a member announcement (show blue)
- `audience`: text/varchar, for future targeting/filtering (optional)

Recommended indexes:
- Index on (`start`, `category`)
- Index on (`announcement`)

Recommended RLS:
- Members may insert/update/delete their own, any authenticated may select all.

> Example SQL:
> ```sql
> create table if not exists events (
>   id bigint primary key generated by default as identity,
>   title text not null,
>   description text,
>   start timestamptz not null,
>   end timestamptz,
>   category text,
>   created_by text,
>   created_at timestamptz default now(),
>   announcement boolean default false,
>   audience text
> );
> -- Add RLS policies as appropriate.
> ```

_This table must exist and support the fields above for calendar/event features. See the frontend code for precise field usage._
